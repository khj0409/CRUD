# Projet 항공기 예약 관리

위 프로젝트는 SAP ABAP을 활용하여 항공기 관리 프로그램 관련 개발 프로젝트입니다.
고객의 정보를 생성 수정할 뿐만 아니라 항공기 편을 예약하고 예약을 취소하는 프로젝트를 담고 있습니다.

또한 두개의 프로그램을 연결하여, 항공편을 조회, 예약, 생성, 수정, 삭제를 실행하는 프로그램입니다.

프로그램 명: SAPMZBZ414_18_PR04

LOGIC 1. BOOKC
스크린 100 : 항공편 조회
    |   BOOKC
스크린 200 - 서브스크린 201 : 항공편 예약 취소
    |   CANCEL, BACK, SAVE : SCREEN 100
  EXIT : 프로그램 종료

LOGIC 2. BOOKN
스크린 100 : 항공편 조회
    |   BOOKN
스크린 300 : 항공편 예약 및 고객 정보 입력
    |   CANCEL, BACK, SAVE : SCREEN 100
  EXIT : 프로그램 종료
